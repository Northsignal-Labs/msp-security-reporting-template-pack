One-command proof

Regenerate all five sample reports

From the repository root, run the filesystem-only sample runner. It uses synthetic JSON fixtures and writes local Markdown/HTML outputs only; it does not use a network, accounts, analytics, forms, contact capture, payment links, quote/invoice workflows, or paid tools.

python3 tools/run_all_sample_generators.py
python3 tools/run_all_sample_generators.py --check-only

Expected result: five workflows checked, ten non-empty generated outputs, and zero errors. If this pack is later published on an approved non-personal channel, this page helps visitors evaluate generator value before opening a public-safe template-request or non-binding commercial-fit signal.
