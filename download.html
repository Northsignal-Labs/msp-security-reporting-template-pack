Start and download guide

Pick the fastest useful path through the Northsignal Labs MSP Security Reporting Template Pack before running any local tools.

Fastest value path

Start with the monthly reporting workflow

  1. Open the MSP monthly security report page for the core recurring reporting use case.
  2. Preview generated examples in sample-outputs.html before running scripts.
  3. Use generator-quickstart.html for the one-command local proof path across all five workflows.
  4. Open request-signal.html on the approved public channel to choose the safe template-request or commercial-fit category before filing anything.
  5. Use the matching Markdown templates, JSON schemas, sample inputs, and local generators below only if they fit your workflow.
  6. Use structured GitHub issue templates for public-safe template requests or non-binding commercial-fit signal; do not use forms, analytics, private inboxes, money-collection links, sales quotes, invoices, or contact collection.
