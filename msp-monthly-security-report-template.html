How to use it in 20 minutes

  1. Export or screenshot the current month’s evidence from Microsoft 365/Entra, EDR, backup, RMM/Intune, ticketing, and firewall/VPN tools.
  2. Fill in the metrics table and mark each area Green, Amber, or Red.
  3. Choose one highest-priority action for the executive summary.
  4. Keep recommendations to five or fewer actions so the client can make decisions.
  5. Attach evidence or link to internal ticket/documentation records.
